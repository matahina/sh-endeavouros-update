# sh-endeavouros-update
Update script for EndeavourOS

## Usage

`eos_update.sh [arg]`

where `[arg]` can be either `cpio` or `dracut`.

***

It uses `yay`, [`update-grub`](https://aur.archlinux.org/packages/update-grub)<sup>`AUR`</sup> and [`sera-git`](https://aur.archlinux.org/packages/sera-git)<sup>`AUR`</sup> (for updating KDE Plasma add-ons).
